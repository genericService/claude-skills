# Changelog

## v2026.11.11-2 (2026-11-11)

- Upgraded `agentic-web` to `2.0.0` after full primary-source audit of every specification and official TypeScript/Python SDK:
  - **`llms.txt` v2 (`llmstxt.org`, `AnswerDotAI/llms-txt@0.0.7`, Lighthouse, Cloudflare)**: Enforced hyphen-only `- ` link bullets, no UTF-8 BOM, single-line summary blockquotes, bracket/paren escaping, Chrome Lighthouse `agentic-browsing` pass/fail rules, Cloudflare streaming Markdown for Agents (`2026-11-09` spec without `x-markdown-tokens`), and verified SDK guidance (`fumadocs-core`, `vitepress-plugin-llms`, `starlight-llms-txt`, `docusaurus-plugin-llms`, `@lacspace/llms-txt`, `turva-llms-txt-validator`, PyPI `llms-txt`).
  - **AdCP v3.2.8+ (`adcontextprotocol.org`, `@adcp/sdk@16.7.0`, PyPI `adcp@9.6.2`)**: Updated TypeScript SDK from deprecated `@adcp/client` to `@adcp/sdk` (including per-tool `@adcp/sdk/types/<tool>` imports and 3.2.8 CLI storyboards), enforced Variant 5 root `"version": "1.0"`, Variant 4+5 composition, `inline_properties` -> `"properties"` companion key, `publisher_properties` XOR selectors, 8-step UTS-46 URL canonicalization, RFC 9421 3.2 `sf-binary` vs Base64URL webhook signing split, and the 7 compact 3.2 commercial lifecycle tools.
  - **RFC 8615, MCP `2026-07-28` (`SEP-2127`), & A2A `v1.0.1`**: Updated SEP-2127 discovery to canonical `/.well-known/ai-catalog.json` (`application/ai-catalog+json`) + `<mcp-url>/server-card` (`v1/server-card.schema.json` reverse-DNS `name`, `<= 100` char `description`), documented MCP v2 SDKs (`@modelcontextprotocol/server@2.4.0` + PyPI `mcp@2.3.0` `MCPServer`), upgraded `agent-card.json` to A2A `v1.0.1` (`supportedInterfaces`, `securityRequirements`, `extendedAgentCard`, `@a2a-js/sdk@1.3.0`, `a2a-sdk@1.3.0`), added RFC 9728 path-insertion table, and hardened RFC 9116 `security.txt` validation.
  - **W3C WebMCP, Crawl Rights & Commerce**: Migrated WebMCP from `navigator.modelContext` to May 2026 `document.modelContext` + `AbortSignal` (`webmcp-types`, `@w3c/webmcp-polyfill`, `@mcp-b/global@6.2.0`), documented dual IETF `aipref` `Content-Usage` (`y`/`n` tokens) + Cloudflare `Content-Signal` (`yes`/`no`), W3C `TDMRep` JSON array validation, `RSL 1.0`, UCP `2026-08-25` (`@ucp-js/sdk`, `ucp-sdk`), ACP `2026-04-17` (`/.well-known/acp.json`), and `x402` v2 (`PAYMENT-REQUIRED` / `PAYMENT-SIGNATURE` / `PAYMENT-RESPONSE`, CAIP-2, `@x402/*@2.30.0`, PyPI `x402@2.27.0`).
- Upgraded `llms-txt` to `3.1.0` with `AnswerDotAI/llms-txt` parser regex safeguards, Chrome Lighthouse `llms-txt` rules, RFC 8288 header quoting, and verified SDK package table.
